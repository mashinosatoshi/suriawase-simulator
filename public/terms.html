利用規約

〔公開日〕 制定

この規約は、運営者が提供するゲーム「すり合わせシミュレーター」(以下「本ゲーム」) の利用条件を定めます。本ゲームを利用した時点で、この規約に同意したものとみなします。

1. 本ゲームについて

本ゲームは、AI が演じる相手と対話する、架空のシナリオのゲームです。AI の会社 (Anthropic・OpenAI・Google) の API を、あなた自身の API キーでブラウザから直接呼び出して動きます。

2. API の料金

  • AI の呼び出しの料金は、API キーの持ち主であるあなたが、その AI の会社に支払います。運営者は料金を負担せず、返金にも応じられません。
  • このゲーム専用のキーを作り、各社の管理画面で上限額を設定してから使うことをおすすめします (手順はゲームの「AI の設定」にあります)。

3. 入力してはいけないもの

話題や会話は AI の会社に送られます。次のものは入力しないでください。

  • 個人情報 (あなたや他の人の氏名・住所・連絡先など)
  • 機密情報 (勤務先の非公開情報など)
  • API キー・パスワードなどの秘密情報 (本ゲームは、キーらしい文字列を見つけると送信を止めますが、すべては見分けられません)

4. 禁止事項

  • 法令や公序良俗に反する利用
  • 利用する AI の会社の利用規約・利用ポリシーに反する利用
  • 他人の API キーを、持ち主の許可なく使うこと
  • 本サイトへの攻撃や、運営を妨げる行為

5. AI の出力について

AI が作るシナリオ・台詞・振り返りは架空のもので、正確さや適切さは保証されません。現実の判断の根拠にしないでください。

6. 利用の条件

利用する AI の会社が定める API の利用条件 (年齢など) を満たしている必要があります。

7. 無保証・責任の範囲

本ゲームは現状のまま提供し、不具合がないことや、いつでも利用できることは保証しません。運営者は、法令で認められる範囲で、本ゲームの利用によって生じた損害 (API の料金を含みます) について責任を負いません。

8. 変更・停止

運営者は、予告なく本ゲームの内容を変更し、または提供を停止することがあります。

9. 規約の改定

この規約を改定するときは、このページでお知らせします。

10. 準拠法

この規約は日本法に従って解釈します。
