プライバシーポリシー

〔公開日〕 制定

このゲーム「すり合わせシミュレーター」(以下「本ゲーム」) は、ブラウザの中だけで動きます。運営者は、あなたの API キーや会話の内容を受け取りません。

1. 運営者が受け取らないもの

  • API キー: このページ (ブラウザ) のメモリにだけ置き、あなたが選んだ AI の会社へ直接送ります。運営者のサーバーには送られず、どこにも保存しません。ページを閉じるか「消す」を押すと消えます。
  • ゲームの内容: シナリオの希望・あなたの発言・AI の返答・振り返りは、ブラウザの中にだけあり、運営者には届きません。ページを閉じると消えます。
  • Cookie・アクセス解析・広告: 使っていません。ブラウザの保存領域 (localStorage など) も使っていません。

2. AI の会社に送られるもの

あなたが選んだ AI の会社 (Anthropic・OpenAI・Google のいずれか) に、ブラウザから直接、次のものが送られます。

  • API キー (その会社の利用者として認証するため)
  • シナリオの希望・あなたの発言・ゲームの進行に必要な情報 (AI が返答を作るため)

これらは、あなたとその会社との契約 (利用規約・プライバシーポリシー) に従って扱われます。運営者は関与できず、削除することもできません。

  • Anthropic (Claude): www.anthropic.com/legal/privacy
  • OpenAI (GPT): openai.com/policies/privacy-policy
  • Google (Gemini): ai.google.dev/gemini-api/terms

Gemini の無料枠 (請求を設定していないプロジェクト) では、入力と応答が Google のサービス改善に使われ、人が読むことがあると定められています。どの会社を使う場合も、個人情報や機密情報は入力しないでください。

3. このサイトの配信に伴う記録

本ゲームの画面のファイルは、Google Cloud の Cloud Run から配信しています。アクセスのたびに、IP アドレス・ブラウザの種類・アクセス日時などが、運営者の Google Cloud プロジェクトのログ (Cloud Logging) に記録されます。このログは 30 日で自動的に削除されます。運営者がこのログを見るのは、障害の調査や不正な利用への対応に必要な場合に限ります。

4. お問い合わせ

GitHub の Issues で受け付けています: github.com/mashinosatoshi/suriawase-simulator/issues

Issues は誰でも読める場所に公開されます。個人情報や API キーは書かないでください。セキュリティ上の問題は、公開の Issue ではなく、リポジトリの「Security」タブの「Report a vulnerability」から非公開でお知らせください。

5. 改定

このポリシーを改定するときは、このページでお知らせします。
